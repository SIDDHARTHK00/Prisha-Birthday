PRISHA BIRTHDAY SURPRISE
==========================

This is a 7-step interactive birthday website for Prisha.

Files:
- index.html
- assets/photo1.jpg ... photo10.jpg

How to test:
1. Keep the folder structure unchanged.
2. Open index.html in a modern browser.
3. For phone testing, upload the whole folder to a static web host.

How to put it online:
- Upload the complete folder to any static hosting service.
- Make sure index.html is at the root.
- Share the resulting HTTPS link on WhatsApp.

Music:
The site starts a tiny soft Web Audio ambient melody after user interaction. If you want a specific song, add an audio file and replace the startAudio() function with an <audio> element. Using music you have permission to share avoids copyright issues.
